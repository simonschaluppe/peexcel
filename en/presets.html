Quick selection with presets

Preset catalogue: look up standard cases and their values

Presets simplify entering typical building configurations and technical systems. Instead of setting many parameters individually, select a related parameter package.

This speeds up model creation and comparison of design variants. Adapt the applied values to your project afterwards.

Where in PEExcel? ▶ Quick Start → Schnellauswahl (quick selection).

Alternatively, select presets on individual technical sheets or the klimaaktiv PEQ ribbon.

Applying a preset

Where in PEExcel?

  1. Save the baseline: Save the current inputs as a variant.
  2. Select a preset: Choose the desired configuration in quick selection.
  3. Check inputs: Review applied values on the relevant technical sheet.
  4. Recalculate: Run calculation and assess the affected balances on the results sheet.
  5. Compare variants: Save the new state and use variant comparison.
WarningCaution

Presets can overwrite existing inputs. Save the baseline first and do not rely on Excel’s Undo function.

Example: changing the heating system

This example investigates a variant with a different heat supply.

Ribbon: klimaaktiv PEQ → Heizung → Auswahl Heizsystem

  1. Select “Fernwärme” (district heating).
  2. On 🔥H Heizung, check the applied parameters, especially energy carrier, Maximale Heizleistung (maximum heating capacity) and generation efficiency.
  3. Recalculate.
  4. Check final-energy carriers and primary-energy balance on the results sheet.
  5. Save the result as a separate variant.

The comparison shows the effects of supply concepts within the model assumptions.

WarningCaution

A preset does not replace project-specific system sizing.

Available input groups

Input group Further information
Geometry, new construction and refurbishment District and project parameters
Envelope quality, airtightness, shading and construction type Building physics
Heating, emission, cooling, hot water and ventilation Building services
Photovoltaics PV areas and generation profiles
Flexibility and storage Storage and control
Mobility Location, private transport and EVs
Life-cycle assessment Construction measures and building services

Presets and project-specific inputs

A preset is an input aid, not project-specific evidence. Its name does not describe every active setting. The actual parameter values applied are decisive.

Check technical capacities, system shares, setpoints, losses and activation switches for plausibility and agreement with the project.

Declaration: Replace examples and estimates with suitable project data. Parameters marked as declaration values are mandatory for verification, although free model variants may use different values.
